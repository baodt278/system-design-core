**Lần theo ⟦yêu cầu|request⟧ từ ⟦máy khách|client⟧ đến ⟦phản hồi|response⟧:**
@36
Người dùng tải ảnh lên:
1. Máy khách → Máy chủ API
2. API → Kiểm tra tính hợp lệ của tệp
3. API → Tải lên S3
4. API → Thêm tác vụ vào hàng đợi
5. API → Trả về phản hồi "đang xử lý"
6. Worker → Xử lý tác vụ thay đổi kích thước
7. Worker → Tải ảnh đã thay đổi kích thước lên S3
8. Worker → Cập nhật cơ sở dữ liệu
9. Người dùng hỏi vòng (poll) API → Lấy trạng thái

Xác định:
- Ranh giới giữa đồng bộ và bất đồng bộ
- Chỗ nào nên thêm bộ nhớ đệm
- Chỗ nào có thể xảy ra sự cố
